# Mapping SharePoint officiel

- CLI - Clients : ClientID permanent, Nom affichable modifiable
- SIT - Sites : SiteID permanent, ClientID, Nom affichable, Domaine
- USR - Utilisateurs : UserID permanent, Email, Nom affichable
- DSE - Acces Sites : UserID, ClientID, SiteID, Role, droits
- ART - Articles : SiteID, slug, contenu, statut
- MDU - Produits : SiteID, slug, prix, licence, actif
